# Контракт интеграции v0.1

Рабочие точки входа: `ArcSolver.solve(graph, snapshot, time_limit_s)`, `validate(graph, snapshot, routes)`, CLI `solve`, `demo` и `validate`. Схемы JSON публикуются CLI. Внешний HTTP-адаптер можно согласовать по следующим операциям.

| Будущая операция | Вход и выход |
|---|---|
| `POST /api/v1/scenarios`, `GET /api/v1/scenarios/{id}` | `ScenarioSnapshot`, ссылка и правила неизменяемости по паре ID и хеш |
| `POST /api/v1/plans`, `GET /api/v1/plans/{id}` | Ссылка на снимок, метод, лимит секунд. Идентификатор задания, очередь и итоговый `Plan` |
| `GET /api/v1/plans/{id}/geojson` | `FeatureCollection` с порядком проезда, режимами и UTC |
| `POST /api/v1/plans/{id}/validate` | Повторный расчёт `Validation` на том же графе и снимке |
| `POST /api/v1/compare` | Несколько методов на одном снимке, переменные затраты сравниваются при полном покрытии обоих |
| `POST /api/v1/plans/{id}/replan` | Следующий этап. Снимок, подтверждённые события и остаточное состояние |
| `GET /api/v1/health` | Доступность и версии компонентов после появления HTTP-сервиса |

Статусы допустимости: `feasible_candidate`, `no_feasible_candidate`, `proven_infeasible`. Последний публикуется с отдельным необходимым ресурсным условием, когда минимально возможное время сервиса выше суммарной длительности смен. `timeout` является причиной окончания поиска и может сопровождать допустимый план. `pool_optimal` и `pool_gap` относятся к сгенерированному пулу. `gap_if_proven` остаётся `null` для глобальной задачи. Общий ответ плана использует `ok` или `partial`. Ошибки входа CLI завершают расчёт с ненулевым кодом, в HTTP им соответствует `invalid_input`.

Для совместимости с исследовательским контрактом сохранены `graph_version` и `as_of`. Текущий срез получает пустые `observations` и `weather: null`. При подключении опционального прогноза входной адаптер должен проверять `observed_at`, `received_at`, `issue_at`, `valid_from/to` относительно `as_of`. Погодные данные и изменения состояния не являются обязательными для планирования по готовым заданиям.
