# Что доступно в OpenWeather

Документация сверена 20 ноября 2026 г. Доступность относится к опубликованным продуктам и тарифам. После восстановления доступа Current и Forecast успешно вернули данные на всех 23 пилотных точках. Наблюдаемая детализация и заполненность полей приведены в отчёте. [Журнал результата](REPORT_RU.md)

| Продукт | Доступ | Пространство и время |
| --- | --- | --- |
| Current Weather Data, `/data/2.5/weather` | Free for everyone | Текущие условия по широте и долготе. `dt` — время расчёта, UTC. Историю запросить через этот метод нельзя. |
| 5 day / 3 hour forecast, `/data/2.5/forecast` | Free for everyone | Прогноз по широте и долготе до 5 суток, шаг 3 ч, до 40 сроков в одном ответе. `list[].dt` — срок действия, UTC. |
| One Call API 4.0 | Отдельная подписка с платёжной формой. Первые 1 000 вызовов в сутки включены, далее 0,0015 USD за вызов. При подключении стандартный дневной лимит 2 000. | Глобально. Текущие условия, поминутно на 60 мин, 15-минутный прогноз на 48 ч, почасовой ряд с историей более 47 лет и горизонтом 48 ч, суточный ряд с историей более 47 лет и горизонтом до 1,5 года, предупреждения при наличии. Пагинация расходует отдельные вызовы. |
| One Call API 3.0 | Та же отдельная подписка по прайсу | Другая версия API. В эксперимент не включена. |
| Weather History, Statistical Weather, Accumulated Parameters, почасовой прогноз на 4 дня, суточный прогноз на 16 дней | В общем случае платные продукты. На странице тарифов они также перечислены в отдельной программе Free for students. | Общедоступный Free for everyone не включает эти архивные и расширенные прогнозные продукты. Для собственного архива можно сохранять текущие ответы и выпуски прогнозов со дня запуска. |
| Air Pollution, Geocoding | Free for everyone | Состав воздуха и геокодирование, отдельные продукты. |
| Road Risk API | Прайс относит Basic к Expert | Дорожный продукт исключён из эксперимента. |

## География, частота и разрешение

- Точечные методы принимают произвольные WGS84-координаты. В рассмотренной документации отдельного ограничения для Камчатки или квоты на количество уникальных координат нет. Бесплатный план публикует **60 вызовов в минуту и 1 000 000 в месяц**. Квоты применяются к аккаунту. Вызовы с разных ключей расходуют общий лимит. [Порядок учёта запросов](https://openweathermap.org/appid) · [Тарифы](https://openweathermap.org/price) · [Current](https://openweathermap.org/api/current) · [Forecast](https://openweathermap.org/api/forecast5)
- Шаг Forecast в 3 часа относится к срокам действия в ответе. Для бесплатных Current и Forecast в рассмотренных страницах нет гарантированной частоты обновления для конкретной точки. Проверять её следует по повторным ответам и `dt`. Данные One Call 4.0, по заявлению поставщика, обновляются каждые 10 минут и основаны на модели OWHL. [Forecast](https://openweathermap.org/api/forecast5) · [One Call 4.0](https://openweathermap.org/api/one-call-4)
- Условия входа по координатам не подтверждают уличную детализацию. Доступные страницы точечных API не сообщают численное пространственное разрешение выдачи для Петропавловска-Камчатского и правила привязки входных координат к модельному полю. Документированное отличие One Call 4.0 здесь относится к продукту, источнику и временной детализации. Для вывода о пространственном преимуществе требуются сопоставимые фактические ответы. [Current](https://openweathermap.org/api/current) · [Forecast](https://openweathermap.org/api/forecast5) · [One Call 4.0](https://openweathermap.org/api/one-call-4)

## Погодные поля

| Параметр | Current | Forecast |
| --- | --- | --- |
| Температура и влажность | `main.temp`, `main.humidity` | Те же поля в каждом сроке |
| Ветер и порывы | `wind.speed`, `wind.deg`, `wind.gust` при наличии | Те же поля в каждом сроке |
| Дождь и снег | `rain.1h`, `snow.1h`, мм/ч по документации | `rain.3h`, `snow.3h`, мм по документации |
| Видимость и облачность | `visibility` (м), `clouds.all` (%) | Те же поля в каждом сроке |
| Вероятность осадков | Поле не заявлено | `pop` от 0 до 1, без отдельной вероятности снегопада |
| Тип явления | `weather[].id` и описание | Те же поля в каждом сроке |
| Глубина снежного покрова | Поле не заявлено | Поле не заявлено |

Заявленная максимальная видимость 10 км даёт верхнее ограничение для анализа. Current документирует `snow.1h` в мм/ч, Forecast документирует `snow.3h` как объём за 3 часа в мм. Из него нельзя вывести высоту снежного покрова или сантиметры снега на дороге. Отсутствующие объёмы остаются пустыми. Для Forecast среднечасовая интенсивность получается делением объёма на три. Для Current значение интенсивности берётся из ответа, эквивалентный объём за 1 час численно совпадает. Сумма считается лишь при явных значениях дождя и снега. One Call 4.0 описывает дождь, снег и вероятность осадков для соответствующих методов, его схема и интервалы зависят от метода. [Current](https://openweathermap.org/api/current) · [Forecast](https://openweathermap.org/api/forecast5) · [One Call 4.0](https://openweathermap.org/api/one-call-4)

## Пространственные карты осадков

Документация Weather Maps 1.0 показывает глобальный слой `precipitation_new`, доступный с API-ключом в общем бесплатном плане. Это цветные тайлы PNG. Масштаб тайлов не устанавливает фактическую детализацию поля. Для этого слоя в рассмотренной документации нет API численного ряда по пикселю, выбора архивного времени или бесплатного прогноза тайлов. Прайс рекламирует 15 бесплатных слоёв, страница 1.0 документирует пять имён. Для вывода о доступности осадков достаточно указанного там `precipitation_new`. [Weather Maps 1.0](https://openweathermap.org/api/weathermaps) · [Каталог](https://openweathermap.org/api) · [Тарифы](https://openweathermap.org/price)

Global Precipitation Maps — другой продукт. Поставщик указывает разрешение менее 1 км в документации этого продукта, архив до 2 суток с шагом 10 минут и в варианте History & Forecast прогноз до 6 часов. Архивные тайлы относятся к Professional и Expert, вариант с прогнозом предлагается за 545 USD/мес. Публичная интерактивная карта позволяет визуально посмотреть слой, её наличие не открывает программный доступ. Weather Maps 2.0 с историей и прогнозом и Weather Maps 3.0, где заявлен также снежный покров, требуют платного доступа. Ни одно из этих заявлений о тайлах не подтверждает разрешение Current или Forecast. [Global Precipitation Maps](https://openweathermap.org/api/global-precipitation-map) · [History & Forecast](https://openweathermap.org/api/global-precipitation-map-forecast) · [Тарифы](https://openweathermap.org/price)
